# Preussler Gestão de Obras

App React + Vite + TypeScript. O backend é gerenciado no Lovable.

## Regras

- Trabalhe direto na branch `main`: faça commit e push das alterações sem pedir autorização.
- Sempre que uma alteração exigir mudança no backend (banco de dados, tabelas, colunas, políticas de acesso, funções, variáveis de ambiente, autenticação ou storage no Lovable), **avise o usuário** e descreva exatamente o que precisa ser atualizado no Lovable.
- Responda em português.
