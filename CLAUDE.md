# Preussler Gestão de Obras

App React + Vite + TypeScript. O backend é gerenciado no Lovable.

## Regras

- Sempre que uma alteração exigir mudança no backend (banco de dados, tabelas, colunas, políticas de acesso, funções, variáveis de ambiente, autenticação ou storage no Lovable), **avise o usuário antes de publicar/enviar** e descreva exatamente o que precisa ser atualizado no Lovable. Só publique depois que o usuário confirmar que o backend foi atualizado.
- Responda em português.
